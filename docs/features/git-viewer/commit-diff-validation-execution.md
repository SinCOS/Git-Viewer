# Commit / Diff 回归验证记录

2026-10-27 对截图对齐后的实现执行完整检查。调整旧 UI 测试，使其按当前 Changes 在 Staged Changes 之前的顺序验证选择和键盘导航，并区分左侧折叠状态与始终显示的底部文件列表；根目录文件直接显示，子目录仍可独立折叠。

首次 `make check` 发现 SSH worktree 集成测试中的仓库身份不一致：经符号链接路径打开时，相对 Git common-dir 以原始路径拼接，重新打开后路径形式改变。SSH 仓库探测改为请求 Git 输出绝对 common-dir。真实 loopback SSH 隔离仓库的创建、状态、脏目录拒绝和删除生命周期测试通过；测试路径包含引号、空格、中文和 shell 特殊字符。

修正后完整 `make check` 通过，包括格式、Go/MyGo vet、全量 race 测试和本机原生构建。`make smoke` 创建原生窗口，完成主线程数据更新并正常停止后台任务。首次沙箱内检查因无法读取系统 Go 构建缓存失败，授权后重跑。

这些结果不等同于截图视觉或物理交互验收。参考尺寸和 1000×550、浅深主题、鼠标键盘、终端与默认编辑器行为仍需真实窗口检查；CD001–CD007 保持未完成。loopback 测试不代表其他远程主机或 Apple Silicon 真机验收。
